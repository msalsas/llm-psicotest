# T2.5 resurfacing contract

This contract covers one PR. The PR moves the merged T1+T2 codebase from the DESIGN v1 Spanish surface to the DESIGN v2 English surface, as DESIGN v2 §14 ("Resurfacing before T3") requires. DESIGN v2 is the source of truth. The shipped T2 contract, plus its addendum, is the baseline. Wherever this document does not say otherwise, every rule in the T2 contract still holds word for word.

Lines marked `HOLE:` are places where neither DESIGN v2 nor the T2 contract fixes the behaviour. Each one pins a default. All of them are collected in §11.

---

## 0. Scope and invariants

The PR is a **resurfacing**. A reviewer must reject it if any of these invariants is broken.

## 1. Style rules (delta to T2 §0)

- **Pure ASCII source.** Every byte of every `src/psicotest/**/*.py` file is `< 0x80`. The T2 exemption for `áéíóúüñÁÉÍÓÚÜÑ¿¡` is gone. The English surface needs none of those characters, so they are **removed**, not escaped. Existing `\uXXXX` escapes that carry meaning stay exactly as shipped (they are already ASCII bytes): `×` in `SCI_RE`, `≈` in `APPROX_RE`, `−` in `parse_number`/`parse_scalar`, `€ £ ° º` in `LEAD_NUM_RE`/`UNIT_TAIL_RE`, `•` in `ITEM_RE`, and the NBSP family in `preclean`.
- **Tests are pure ASCII too.** Every byte of every `tests/**/*.py` file is `< 0x80`. A test input that must be non-ASCII (CJK, NBSP, `×`, `€`, the §5.4 boundary probes) is written as a `\uXXXX`/`\UXXXXXXXX` escape, as T2 already required for non-Spanish characters. HOLE H10.
- Everything else in T2 §0 still applies (Decimal construction rules, no ambient context, no LLM judgment, banned constructs).

### 5.2 `text.NUMBER_WORDS`

These are literal tables with folded keys. Per the addendum, nothing is added beyond what is listed here.

```python
SMALL = {
    "zero": 0, "one": 1, "two": 2, "three": 3, "four": 4, "five": 5, "six": 6,
    "seven": 7, "eight": 8, "nine": 9, "ten": 10, "eleven": 11, "twelve": 12,
    "thirteen": 13, "fourteen": 14, "fifteen": 15, "sixteen": 16, "seventeen": 17,
    "eighteen": 18, "nineteen": 19,
}
TENS = {
    "twenty": 20, "thirty": 30, "forty": 40, "fifty": 50,
    "sixty": 60, "seventy": 70, "eighty": 80, "ninety": 90,
}
NUMBER_WORDS = {
    **SMALL,
    **TENS,
    **{
        f"{t}-{u}": TENS[t] + SMALL[u]
        for t in TENS
        for u in ("one", "two", "three", "four", "five", "six", "seven", "eight", "nine")
    },
    "one hundred": 100,
    "a hundred": 100,
}
```

- **Size:** 20 (SMALL) + 8 (TENS) + 8 × 9 = 72 (hyphenated composites, 21–99 except multiples of ten) + 2 (scale) = **102 keys**. The values cover exactly `0..100`.
- `SMALL` and `TENS` keep their names. The unit tuple and the scale entries may be inline, as shown.
- **Forbidden.** None of these is a key, and each gives `parse_number(s) == (None, set())`:
  - false composites: `onety`, `tenty`, `eleventy`, `twenty-zero`, `twenty-ten`, `ten-one`, `nineteen-one`
  - misspelling: `fourty`
  - spaced composite: `twenty two` (HOLE H2)
  - incomplete scale words: `hundred`, `a`, `one hundred one`, `one hundred and one`, `two thousand`
  - spoken decimal: `twelve point three five` (HOLE H1)
  - signed word: `minus five`

### 5.3 `parse_number` separator table (E1)

Steps 1–3 and the helpers `D(i, f)` and `TH(c)` stay exactly as in T2 §3.3. Step 4 is the T2 table with `.` and `,` swapped everywhere. The branch numbers and their evaluation order are kept.

| # | Condition on `body` | Rule | Return |
|---|---|---|---|
| B1 | contains both `.` and `,` | `dec` = whichever of `.`/`,` occurs last; `th` = the other. `i, f = body.rsplit(dec, 1)`. If `th in f` or `TH(th)` fails on `i` → `(None, set())` | `(D(i.replace(th, ""), f), {"R2_FAIL"})` |
| B2 | only `.`, exactly once | decimal point | `(D(i, f), set())` |
| B3 | only `.`, ≥ 2 times, `TH(".")` matches | thousands (extension) | `(D(body.replace(".", ""), ""), {"R2_FAIL"})` |
| B4 | only `.`, ≥ 2 times, otherwise | — | `(None, set())` |
| B5 | only `,`, `TH(",")` matches | thousands | `(D(body.replace(",", ""), ""), {"R2_FAIL"})` |
| B6 | only `,`, exactly once, B5 not matched | decimal comma | `(D(i, f), {"R2_FAIL", "FMT"})` |
| B7 | only `,`, ≥ 2 times, B5 not matched | — | `(None, set())` |
| B8 | no separator | integer | `(D(body, ""), set())` |

This matches DESIGN v2 §7.1:
- only `.` → decimal;
- only `,` matching `^\d{1,3}(,\d{3})+$` → thousands + R2_FAIL;
- only `,` otherwise → decimal + R2_FAIL + FMT;
- both separators → last one is the decimal mark + R2_FAIL.

Decimal rendering on the oracle side is `12.35` (§7.3).

### 5.11 English singular lemmatizer (`rules.py`)

`singular_candidates(word)`: `w = fold(word)`. Candidates are appended in this order, then de-duplicated keeping first occurrence:
1. `w`
2. `w[:-1]` if `w` ends with `s`
3. `w[:-2]` if `w` ends with `es`
4. `w[:-3] + "y"` if `w` ends with `ies`
5. `w[:-3] + "f"`, then `w[:-3] + "fe"`, if `w` ends with `ves`
6. `PLURAL_EXCEPTIONS[w]` if present

The Spanish `ces → z` rule is removed.

## 7. Fixtures and fakes

### 7.1 Rewrite rules (byte-level)

Where §7.4 gives an explicit string, that string is authoritative. Every candidate-facing string not listed there follows these rules, in order:

1. The marker `RESPUESTA` becomes `ANSWER`, `ACLARACION`/`ACLARACIÓN` becomes `CLARIFICATION`, and `ANIMAL` stays `ANIMAL`. The case of the original is kept (`respuesta` → `answer`, `Respuesta` → `Answer`).
2. Numbers that the T2 fixture wrote with a comma decimal (`12,35`) are written with a point (`12.35`), and vice versa. Thousands written as `4.567.890.123`/`1.234` become `4,567,890,123`/`1,234`. This keeps every checker verdict invariant (I6).
3. CSP names: `Ana` → `Alice`, `Bruno` → `Brian`, `Carla` → `Clara`, `Dario`/`Darío` → `David`. Initials A/B/C/D, every number and every constraint index stay the same.
4. ST prefix `caja`/`Caja` → `box`/`Box`. ERR `PASO`/`paso` → `STEP`/`step`, `VALOR`/`valor` → `VALUE`/`value`. LOG `caballeros` → `knights`, `bribones` → `knaves`, `espía` → `spy`, and the connector ` y ` → ` and `.
5. Animal nouns: `oveja` → `sheep`, `gato` → `cat`, `ratón` → `mouse`, `pez` → `fish`. The exception is the `test_checkers_r3.py` module-level T17/T18, which use `goat` (HOLE H12).
6. Prose becomes English prose with no animal word, no number other than those in the original, and no `ANSWER:`/`CLARIFICATION:` at line start unless the original had one there.
